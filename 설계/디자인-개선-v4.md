# 현농푸드랩 웹사이트 디자인 개선 v4

작성일: 2026-09-16

## 적용한 내용

- 전체 제목과 본문, 카드, 내비게이션 서체를 Pretendard로 통일했다.
- 메인의 세로 사진 카드를 없애고, PC에서는 사진이 화면 오른쪽 절반과 브라우저 끝까지 채우도록 구성했다.
- PC 메인은 브라우저 높이에 맞춰 620~820px 범위로 커지며, 왼쪽에는 제목과 설명, 행동 버튼이 놓인다.
- 모바일과 태블릿에서는 설명 다음에 사진이 화면 너비 전체로 이어지고 440~720px 범위에서 커진다.
- 기존 현농푸드랩 포인트 색 `#125135`, 진한 색 `#0d3f29`, 옅은 색 `#edf5ef`, 보조 금색 `#be9a50`을 유지했다.
- 현재 세로 사진으로 먼저 반응형 구도를 확인할 수 있게 했으며, 실제 발행용 가로·세로 메인 사진 규격은 `추가-이미지-요청.md`에 정리했다.

## 구현 파일

- 템플릿: `scripts/build-preview.mjs`
- 활성 스타일: `preview/styles-v3.css`
- 생성 결과: `preview/`

현재 결과는 로컬 디자인 미리보기이며 GitHub 푸시와 Cloudflare Pages 운영 배포는 진행하지 않았다.
