# 현농푸드랩 브랜드 사이트 — 현농푸드랩 소개 페이지 수정안 v1

작성일: 2026-09-23
용도: 현재 제작된 소개 페이지의 **디자인 시스템(색·폰트·컴포넌트·레이아웃)은 그대로 두고, 내용만** 이 문서 기준으로 교체한다.

---

## 0. 적용 원칙

1. 디자인 시스템은 바꾸지 않는다. 섹션마다 "컴포넌트"에 적힌 기존 요소를 재사용한다.
2. 이 문서에 없는 문구·수치는 새로 만들지 않는다. 필요하면 `[확인 필요]`로 남긴다.
3. 연도·수치는 이미지가 아니라 **HTML 텍스트**로 넣는다.
4. `[자리표시]` = 자료가 아직 없어 자리만 잡아둔 곳. 자료 확보 시 교체한다.
5. 소개 페이지에 전용 컴포넌트가 이미 있으면 그쪽을 우선한다. 섹션 **순서와 내용**은 이 문서를 따른다.
6. 헤더·푸터는 메인 페이지 수정안과 동일하다. 이 문서에서는 다루지 않는다.

### 컴포넌트 이름 (블로그 페이지 화면 기준)

| 이름 | 생김새 |
|---|---|
| `C-HERO` | 좌측 텍스트(영문 라벨·태그·H1·설명·버튼 2개) + 우측 이미지 |
| `C-BANNER` | 좌측 이미지 + 우측 진녹색 패널 (로고·라벨·제목·설명·수치 3개·버튼) |
| `C-STRIP` | 좌측 제목 + 번호 매긴 항목 3개 가로 나열 |

## 2. 섹션 순서

```
A1 히어로              — C-HERO
A2 걸어온 길           — 텍스트 타임라인 (신규)
A3 왜 식품을 만들었나   — 텍스트 섹션
A4 숫자로 보는 현농     — C-STRIP 또는 수치 행
A5 원료 품종 수상       — 비노출 (HTML 주석 보관)
A6 본사                — 짧은 텍스트
A7 최종 CTA            — C-BANNER
```

## 3. 섹션별 내용

### A1. 히어로 — `C-HERO`
- 영문 라벨: ABOUT HYUNNONG FOOD LAB
- H1: 20여 년 농업 전문기업이 만든 식품, 현농푸드랩
- 설명: 친환경 농자재 기업 현농과 농업 경영컨설팅 기업 현농경영연구소가 함께 세운 식품 전문 회사입니다.
- 버튼1(채움): 바른쌀 누룽지 보기 → 제품 페이지
- 버튼2: 없음 (이 페이지의 구매 버튼은 A7에 둔다)
- 이미지: `about-hyunnong.jpg` — 본사 사옥
- alt: 현농푸드랩 본사 사옥 전경

### A2. 걸어온 길 — 텍스트 타임라인 (이미지 없음)
- 섹션 라벨: OUR STORY
- 제목: 걸어온 길

| 연도 | 내용 |
|---|---|
| 2007 | (주)현농 설립 — 친환경 농자재 제조·판매 |
| 2013 | (주)현농경영연구소 설립 — 농업인 교육·경영컨설팅 |
| `[확인 필요: 연도]` | (주)현농푸드랩 설립 |
| `[확인 필요: 연도]` | 첫 제품 바른쌀 즉석 누룽지 출시 |

- 모바일: 세로 1열 (연도 → 내용)
- 연도 미확정 행은 확정 전까지 숨김.

### A3. 왜 식품을 만들었나 — 텍스트 섹션
- 제목: 농사 곁에서 쌓은 경험을 식탁으로
- 본문:
  > 현농은 2007년부터 친환경 농자재를 만들며 친환경·유기농 재배 경험을 쌓아왔습니다.
  > 현농경영연구소는 2013년부터 농업인 교육과 경영컨설팅으로 농산물 지식과 생산자 네트워크를 쌓아왔습니다.
  > 그 경험으로 만든 첫 제품이, 유기농으로 재배한 우리쌀을 간편하게 드실 수 있도록 만든 바른쌀 즉석 누룽지입니다.
- 마지막 한 줄: 앞으로 우리 농산물로 만든 가공식품을 하나씩 늘려갈 계획입니다.
- 텍스트 링크: 바른쌀 누룽지 보기 → 제품 페이지

### A4. 숫자로 보는 현농 — `C-STRIP` 또는 수치 행
- 제목: 숫자로 보는 현농

| 수치 | 설명 |
|---|---|
| 2007년 | (주)현농 설립 |
| 2013년 | (주)현농경영연구소 설립 |
| 800회 이상 | 농업인 교육 |
| 3,000회 이상 | 농업 경영컨설팅 |

- `[자리표시: 근거 문서 확보 후 수치 최종 확인]`
- 수치 옆에 "최다", "최고" 같은 수식어를 붙이지 않는다.

### A5. 원료 품종 수상 — **출처 확보 전 비노출**
- 보관 내용: 원료 품종 '천지향5세' — 2024 대한민국 우수품종상 대통령상 수상 품종
- 노출 조건: 원출처(공식 발표·보도) 링크 확보.
- 노출 시 규칙: 수상 주체가 **품종**임을 명확히 적는다. 제품이나 회사가 받은 상으로 읽히지 않게 한다.
- 공개 페이지에 "확인 중" 문구로 두지 않는다. HTML 주석으로만 보관.

### A6. 본사 — 짧은 텍스트
- 내용: 현농푸드랩 본사 · 전남 장성 `[확인 필요: 상세주소]`
- 지도 삽입 없음 (방문형 사업 아님, 전국 배송).
- `[자리표시: 현농·연구소 현장 사진 확보 시 이미지 추가]`

- 제목: 현농푸드랩의 첫 제품,<br>바른쌀 즉석 누룽지
- 설명: 국산 유기농쌀 100%. 뜨거운 물 붓고 3분이면 완성됩니다.
- 수치 3개: 한 봉 **40g** / 열량 **152kcal** / 원료 **국산 유기농쌀**
