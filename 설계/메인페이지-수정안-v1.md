작성일: 2026-09-23
용도: 현재 제작된 메인 페이지의 **디자인 시스템(색·폰트·컴포넌트·레이아웃)은 그대로 두고, 내용만** 이 문서 기준으로 교체한다.

---

## 0. 적용 원칙

1. 디자인 시스템은 바꾸지 않는다. 섹션마다 "컴포넌트"에 적힌 기존 요소를 재사용한다.
2. 이 문서에 없는 문구·수치는 새로 만들지 않는다. 필요하면 `[확인 필요]`로 남긴다.
3. 수치·인증번호는 이미지가 아니라 **HTML 텍스트**로 넣는다.
4. `[자리표시]` = 자료가 아직 없어 자리만 잡아둔 곳. 자료 확보 시 교체한다.
5. 메인 페이지에 전용 컴포넌트가 이미 있으면 그쪽을 우선한다. 섹션 **순서와 내용**은 이 문서를 따른다.

### 컴포넌트 이름 (블로그 페이지 화면 기준)

| 이름 | 생김새 |
|---|---|
| `C-HERO` | 좌측 텍스트(영문 라벨·태그·H1·설명·버튼 2개) + 우측 이미지 |
| `C-CARD3` | 이미지 카드 3열 (이미지 + 제목 + 번호 + 설명 + 텍스트 링크) |
| `C-BANNER` | 좌측 이미지 + 우측 진녹색 패널 (로고·라벨·제목·설명·수치 3개·버튼) |
| `C-STRIP` | 좌측 제목 + 번호 매긴 항목 3개 가로 나열 |

## 3. 상단 띠 · 헤더

### 상단 띠 (유지)
- 문구: 쌀 한 톨부터 한 그릇까지, 현농푸드랩의 기록
- 우측 링크: 인스타그램 ↗ / 스마트스토어 ↗

### 헤더
- 로고 → 메인
- 메뉴: 현농푸드랩 소개 / 바른쌀 누룽지 / 블로그
- 우측 버튼: `스마트스토어 ↗` (현재 라벨 유지)
- 링크: `[확인 필요: 스마트스토어 바른쌀 누룽지 상품 상세 URL]` — 스토어 홈이 아니라 상품 상세로 연결
- 모바일: 로고 + 햄버거 메뉴 + 스마트스토어 버튼 1개

## 4. 섹션별 내용

### M1. 히어로 — `C-HERO`
- 영문 라벨: HYUNNONG FOOD LAB
- 태그: 바른쌀 누룽지
- H1: 뜨거운 물 붓고 3분이면 완성되는<br>국산 유기농쌀 100% 즉석 누룽지
- 설명: 유기가공식품 인증까지 받은 쌀로 만들었습니다. 쌀 품종과 배합비까지 공개합니다.
- 버튼1(채움): 스마트스토어에서 구매 ↗ (새 탭)
- 버튼2(텍스트 링크): 바른쌀 누룽지 자세히 보기 → 제품 페이지
- 이미지: `hero-pour.jpg` — 흰 그릇에 뜨거운 물 붓는 장면
- alt: 흰 그릇에 담긴 바른쌀 즉석 누룽지에 뜨거운 물을 붓는 모습

### M2. 핵심 가치 — `C-STRIP` (이미지 없이 번호형 3개)
- 좌측 제목: 이렇게 만들었습니다
- 01 **유기농쌀 100%** — 국산 유기농쌀만 씁니다. 설탕·소금 없이, 튀기지 않았습니다.
- 02 **끓일 필요 없습니다** — 뜨거운 물 붓고 3분. 냄비도 불도 필요 없습니다.
- 03 **쌀 품종까지 공개** — 하이아미 70% + 천지향5세 30%. 배합비까지 숫자로 밝힙니다.

### M3. 제품 요약 — `C-BANNER`

- 수치 3개: 한 봉 **40g** / 열량 **152kcal** / 원료 **국산 유기농쌀**
- 버튼: 바른쌀 누룽지 알아보기 → 제품 페이지

- alt: 바른쌀 즉석 누룽지 단상자와 개별 포장 파우치
