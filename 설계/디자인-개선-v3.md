# 현농푸드랩 웹사이트 디자인 개선 v3

작성일: 2026-09-16

## 참고 범위

NaturaLife Home Page III의 넓은 첫 화면, 낮은 정보 밀도의 헤더, 3열 이미지 카드, 이미지와 설명을 나눈 브랜드 섹션, 타이포 중심의 최신 콘텐츠, 어두운 하단 구조를 참고했다. 참고 사이트의 문구·사진·로고·아이콘·상품 기능은 가져오지 않았다.

## 적용한 내용

- 현농푸드랩의 기존 포인트 색 `#125135`, 진한 색 `#0d3f29`, 옅은 색 `#edf5ef`, 보조 금색 `#be9a50`을 유지했다.
- 상단에 짧은 브랜드 안내와 공식 외부 채널을 두고, 공통 헤더의 메뉴·스마트스토어·모바일 메뉴 동작은 유지했다.
- 홈 첫 화면은 글 설명과 물 붓기 사진을 크게 나누어 보여주고 대표 행동 두 개를 제공한다.
- 먹는 법·원료·구성·보관·활용을 각기 다른 제공 사진으로 보여주는 세 주제 카드를 추가했다.
- 기존에 거의 쓰지 않던 바른쌀 워드마크와 상품 사진을 상품 안내 구간에 사용했다.
- ‘처음 읽는 분께’ 세 글은 짧은 안내 띠로 분리했다.
- 최근 글은 반복되는 사진 대신 제목·요약·분류 중심 카드로 구성해 글이 늘어나도 일관성을 유지한다.
- 전체 글·분류 목록, 글 상세, 상품·소개 페이지와 하단도 같은 시각 언어로 정리했다.
- 자동 슬라이더, 장바구니, 다국어 메뉴 등 현재 사이트에 필요하지 않은 기능은 추가하지 않았다.

## 확인 결과

- 320, 390, 480, 520, 768, 900, 960, 1024, 1440px에서 문서 폭과 화면 폭이 일치해 가로 넘침이 없었다.
- 모바일 메뉴 열기와 Escape 닫기, 전체 검색, 검색 결과 페이지 이동, 글 상세를 실제 브라우저에서 확인했다.
- 생성 HTML 22개의 내부 주소·자산 775건에 누락이 없었다.
- 외부 연결은 Pretendard CDN, 스마트스토어, 인스타그램뿐이다.
- `noindex,nofollow`와 검색 수집 제외 설정은 디자인 미리보기 상태로 유지했다.

현재 결과는 로컬 미리보기이며 GitHub 푸시와 Cloudflare Pages 운영 배포는 진행하지 않았다.
