# 반응형 디자인 미리보기 검증

2026-09-09. 로컬 미리보기 `http://127.0.0.1:8784/` 기준이다.

- 빌드: `npm run preview:build` 성공. 예시 원고 12개, 분류 3개, 한 페이지 최대 8개.
- 홈의 CSS 화면 폭 320·390·약 768·1024·1440px에서 문서 가로 넘침 없음. 넓은 PC에서 목록 708px와 사이드바 300px 확인.
- 홈·글 상세: 모바일 제목 30px, PC 제목 40px, 본문 16px, Pretendard 로딩 확인. 제공 사진과 로고 표시 확인.
- 모바일 메뉴 열기와 Escape 닫기, 글 상세 이동 확인.
- 검색: ‘확인’ 12편 → 검색 2페이지 4편, 없는 검색어 0편 안내 확인. 분류 및 일반 목록 2페이지 이동 확인.
- 브라우저 콘솔 오류 없음. 검사 후 임시 화면 크기 설정 복원.
- 생성 HTML 22개, 내부 경로·앵커 549건, 이미지 치수 79건 검사 오류 없음.
- 원본 제공 이미지 7개의 동일성은 `preview-assets.json`에 기록.
- 별도 임시 폴더에서 예시 데이터 104개로 빌드: 전체 목록 13페이지 × 8개, 누락·중복 없음. 분류별 페이지 경로도 모두 생성됨. 이 데이터는 현재 미리보기에 넣지 않음.

현재 화면의 원고와 게시 정보는 디자인 검토용이다. 공개 원고 작성, 게시일 정렬, 운영 도메인·검색 메타데이터, GitHub 푸시와 Cloudflare Pages 배포는 이번 검증 범위에 포함하지 않는다.
