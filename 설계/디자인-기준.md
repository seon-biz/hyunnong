2026년 9월 9일 · PC와 모바일 반응형 로컬 미리보기 기준. 현재 구현은 [미리보기 홈](/Users/jeongohkseo/Desktop/hyunnong-food-lab/preview/index.html), 스타일은 [styles.css](/Users/jeongohkseo/Desktop/hyunnong-food-lab/preview/styles.css)에 있다. 운영 웹사이트 배포는 하지 않았다. 브라우저에서 홈·글 상세의 PC·모바일 배치와 메뉴·검색·목록 이동을 확인했다. 상세 확인 범위는 문서 끝에 기록했다.

## 디자인 방향과 참고 범위

흰색 바탕에 현농푸드랩 CI 녹색 `#125135`를 버튼·주제 표시·링크에 사용한다. 제목과 본문은 고딕체로 통일하고, PC에서는 넓은 대표 영역과 글 목록·사이드바를 나란히 배치한다. 모바일에서는 같은 콘텐츠를 한 열로 읽는다. 모바일 기기 모양의 프레임이나 화면 전환용 도구는 현재 독자용 화면에 넣지 않는다.

[레오가구 블로그](https://www.reogagu-blog.com/)에서는 레이아웃·서체·글자 크기·간격·반응형 구성만 참고했다. 해당 블로그의 글 내용·소재·제목·카피·브랜드·사진은 참고하거나 복사하지 않았다. 원고 예시는 현농푸드랩의 기존 콘텐츠 기획에서 작성했다.

## 서체와 크기

참고 사이트의 실제 선언을 확인해 **Pretendard v1.3.9**를 사용한다. 실제 CSS 주소는 [Pretendard 정적 스타일시트](https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css)다. 기기 대체 서체는 `-apple-system, BlinkMacSystemFont, "Malgun Gothic", sans-serif`다.

다음은 참고 사이트에서 확인해 현재 CSS에 적용한 주요 읽기 크기다. PC 값은 768px 이상이다.

| 요소 | 모바일 | PC | 굵기 |
|---|---|---|---|
| 본문 | 16px / 행간 1.75(28px) | 동일 | 400 |
| 페이지·글 제목 | 30px / 1.3(39px) | 40px / 1.26(50.4px) | 800 |
| 본문 소제목 h2 | 22px / 1.4 | 26px / 1.4 | 800 |
| 본문 소제목 h3 | 18px / 1.5 | 20px / 1.5 | 700 |
| 글 목록 제목 | 21px / 1.4 | 22px / 1.4 | 700 |
| 글 목록 요약 | 15px / 1.75, 최대 2줄 | 동일 | 400 |
| 글 상세 첫 답 | 17px / 1.65 | 19px / 1.7 | 400 |
| 글 상세 메타 | 13.5px / 1.6 | 동일 | 400 |
| 목록 분류·날짜 | 13px | 동일 | 분류 600 / 날짜 400 |
| 사진 캡션 | 13px / 1.6 | 동일 | 400 |

제목 자간은 `-0.025em`, 목록 제목은 `-0.02em`이다. 홈 대표 글의 요약은 모바일 17px / 1.8, 900px 이상에서는 18px / 1.8로 조정했다. 이는 대표 사진과의 균형을 위한 현농푸드랩 적용값이다. 버튼·메뉴·사이드바의 세부 크기 역시 현재 화면에 맞췄으며 참고 사이트와 모두 같다고 표현하지 않는다.

## PC·모바일 배치

- 전체 폭은 border-box 기준 최대 1160px. 좌우 여백은 기본 24px, 768px 이상 40px, 360px 미만 20px다.
- 홈 대표 영역은 900px 이상에서 글과 사진을 `1.05fr / 0.95fr`, 간격 64px로 배치한다. 그 아래에서는 글 다음 사진 순서로 한 열이다.
- 960px 이상 목록은 `본문 1fr + 사이드바 300px`, 간격 72px다. 최대 화면에서 실제 목록 폭은 708px다. 사이드바는 상단 104px에서 고정된다.
- 960px 미만에서는 사이드바를 목록 뒤로 내린다. 640~959px에서는 사이드바 안의 두 영역을 나란히, 640px 미만에서는 한 열로 배치한다.
- 목록 썸네일은 640px 이상에서 폭 132px·비율 4:3으로 표시한다. 더 좁으면 숨겨 제목과 요약을 먼저 읽게 한다.
- 글 상세는 사이드바 없이 최대 760px, PC 좌우 여백 32px로 실제 본문 폭 최대 696px를 유지한다. 모바일에는 좌우 24px를 둔다.
- 900px 미만에서는 메뉴 버튼을 사용한다. 480px 미만에서는 헤더의 스마트스토어 버튼을 메뉴 안에 둔다. 외부 채널은 공통 하단과 소개 페이지에도 연결한다.

## 글이 계속 쌓이는 목록

주 2편을 52주 발행하면 연 104편이다. 처음부터 전체 목록·세 가지 분류별 경로·검색·페이지 나누기를 제공한다. 목록은 한 페이지에 최대 8편, 104편이면 전체 목록 기준 13페이지다. 실제 운영에서는 게시일 최신순으로 정렬한다. 현재 12편의 예시는 게시일을 만들지 않고 원고 예시로 표시하며, 데이터에 기록한 순서를 사용한다.

홈 첫 화면에 대표 글 한 편을 두고 홈의 최근 목록에서는 그 글을 제외해 반복을 줄인다. 전체 블로그 목록에는 대표 글을 포함한 모든 글이 나온다. 긴 페이지 목록은 처음·마지막·현재 주변 페이지와 말줄임표로 표시한다. 검색은 현재 분류 안의 제목·요약·주요 항목에서 검색어를 찾으며 검색 결과도 8편씩 나눈다.

사이드바는 ‘처음 읽는 분께’와 상품 안내로 구성한다. 조회 데이터가 없는 상태에서 인기 순위로 표현하지 않는다. 글 상세는 짧은 답 → 제공 사진 → 본문 → 자료 안내 → 상품 안내 행동 하나 → 관련 글 최대 두 편 순서다.
