**글 한 편의 작성 방식 — SEO와 GEO를 함께 고려**

권장 순서는 **고객의 질문을 담은 제목 → 첫 문단의 직접적인 답 → 실제 사진·수치 → 조건과 한계 → 관련 질문 → 다음 글 또는 상품 링크**다. 이는 읽기 편하게 만드는 편집 방식이며 AI 전용 필수 서식은 아니다.

예를 들어 40g 양 비교 글은 “이 제품 한 봉은 40g입니다”라는 답부터 제시하고, 그릇 지름·높이를 표시한 사진으로 실제 크기를 보여준다. ‘누구에게나 한 끼로 충분하다’고 결론 내리는 대신 독자가 자기 식사량에 맞춰 판단하도록 돕는다.

블로그 글마다 현농푸드랩 운영 여부, 실제 작성자 또는 검토자, 게시일·실제 수정일, 참고한 원자료를 표시한다. 인증 사진에는 인증 대상과 범위를 설명하고, 시험 자료에는 제품명·조건·반복 횟수·관찰 방법을 적는다. 출처와 작성 주체를 명확히 하는 방향은 Google의 신뢰성 가이드와도 맞는다. [Google 유용한 콘텐츠 가이드](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)

GEO를 위해 가장 먼저 만들 자료는 다음 네 가지다.

1. **현농푸드랩 바른쌀 조리 기록:** 물 양·물의 초기 온도·용기·시간·뚜껑 유무와 관찰 결과. 자체 관찰을 공인시험으로 부르지 않는다.
2. **한 봉·두 봉 실제 양 사진:** 같은 그릇과 촬영 조건으로 비교한다. 제품 사용 장면은 실제 제품으로 촬영한다.
3. **원료·인증 확인 자료:** 라벨과 인증서를 연결하고 품종 정보와 완제품 확인 결과를 구분한다.
4. **최종 제품의 고객 질문·의견 기록:** 실제 후기의 출처·기간·대상을 밝히고, 발췌 때문에 뜻이 바뀌지 않게 한다. 개인 정보는 옮기지 않는다.

핵심 사실과 표는 본문에서 텍스트로 읽을 수 있게 하고 사진·영상으로 보탠다. 원본 영상·시험 조건·충분한 비교 사진은 요약을 읽은 사람이 더 확인하러 방문할 이유가 된다. 검색 질문의 답을 일부러 감추지는 않는다. 네이버도 경험, 일관된 주제, 투명한 운영, 읽기 쉬운 구성과 본문 텍스트를 강조한다. [네이버 콘텐츠 작성 가이드](https://searchadvisor.naver.com/guide/content-basic)

Google에는 특별한 AI 전용 파일이나 스키마가 필수적이지 않다. 질문의 표현만 바꿔 비슷한 글을 대량 생산하는 방식을 우선하지 않는다. 다른 AI 서비스의 노출 방식까지 Google 지침과 동일하다고 단정하지 않으며, 실제 인용 여부는 서비스별로 확인한다. [Google 생성형 검색 가이드](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)

**독립 웹사이트에 필요한 검색 기본 설정**

사이트 제작 시에는 다음 항목을 담당자에게 전달한다.

- 네이버 서치어드바이저에 도메인을 등록하고 사이트맵과 RSS를 제출한다. 공개 글의 수집 차단 여부를 확인한다. [네이버 검색 최적화 안내](https://searchadvisor.naver.com/guide/seo-basic-intro)
- Google Search Console에 사이트를 등록하고 공개 글의 색인·검색 노출 상태를 확인한다. 핵심 텍스트와 내부 링크를 검색엔진이 읽을 수 있게 한다. [Google AI 검색의 기본 요건](https://developers.google.com/search/docs/appearance/ai-features)
- 글마다 내용에 맞는 고유한 제목·설명문·대표 이미지를 둔다. 단어 반복과 인기 키워드 나열은 피한다. [네이버 제목·설명문 가이드](https://searchadvisor.naver.com/guide/markup-content)
- 글에 맞는 Article 또는 BlogPosting 정보를 넣는다면 작성자·날짜·이미지가 실제 본문과 일치하도록 한다. 구조화 데이터는 콘텐츠를 대신하지 않는다. [Google Article 안내](https://developers.google.com/search/docs/appearance/structured-data/article)

가격·배송·구성처럼 바뀌는 내용은 확인한 날짜를 적고 변경 시 수정한다. 연도 표기가 필요한 가격·구성 비교 글에만 실제 기준 연도를 사용한다. 날짜만 바꿔 새 글처럼 보이게 하거나, 한 글을 유사한 여러 주소로 발행하지 않는다.

**스마트스토어 연결과 측정**

정보 글에서는 구매 가이드로 이동한 비율을, 구매 가이드에서는 스마트스토어 홈으로 이동한 비율을 본다. 현재 홈 링크 클릭은 특정 상품·옵션 조회로 집계하지 않는다. 구체적인 상품 URL을 확보하면 도착 화면이 글에서 설명한 제품·구성과 맞는지 확인한 뒤 상품 링크로 사용한다.

독립 블로그의 GA4에서는 외부 링크 클릭을 측정할 수 있다. 이를 이용해 어떤 글·버튼에서 스마트스토어로 나갔는지 본다. 이 클릭을 실제 구매로 집계하지 않는다. [GA4 외부 링크 클릭 측정](https://support.google.com/analytics/answer/13566436?hl=en)

스마트스토어 측은 공식 사용자정의 채널 파라미터를 사용한다. 아래는 스토어 연결 주소 뒤에 붙일 값의 설계 예시이며, 링크는 스토어에서 유입이 기록되는지 시험한 뒤 사용한다. 현재 연결 주소는 스토어 홈이며, 상품 URL을 확보하면 해당 링크도 별도로 시험한다.

| 항목 | 예시 |
|---|---|
| nt_source | hyunnong.blog |
| nt_medium | content |
| nt_detail | buying-guide |

nt_source와 nt_medium은 필수이며, nt_detail로 글이나 위치를 구분할 수 있다. 사용자정의 채널 보고서에서 유입을 확인한다. UTM만 붙이면 스토어 주문까지 자동으로 연결된다고 가정하지 않는다. 실제 구매 성과는 스토어 보고서의 측정 기준에 맞춰 확인한다. [스마트스토어 사용자정의 유입 공식 안내](https://help.sell.smartstore.naver.com/faq/content.help?faqId=5553)

| 구간 | 볼 지표 | 해석 |
|---|---|---|
| 검색 발견 | 검색어별 노출·클릭, 글별 검색 방문 | 어느 질문에 대한 답이 발견되는가 |
| 블로그 내부 | 정보 글 → 구매 가이드 이동 | 상품 확인으로 이어지는 질문은 무엇인가 |
| 스토어 연결 | 스토어 홈 링크 클릭, 스토어 사용자정의 유입 | 실제 매장 방문을 만드는 글은 무엇인가 |
| 구매 | 스토어에서 확인 가능한 유입 채널별 구매 성과 | 클릭과 구매 사이의 차이는 무엇인가 |
| GEO | 실제 출처 링크·브랜드 언급, 확인 가능한 AI 유입 | 어떤 원자료가 인용되는가 |

단순 질문 몇 번으로 얻은 AI 답변을 전체 노출 성과로 해석하지 않는다. 확인할 때는 날짜·서비스·질문·실제 출처 URL을 기록한다. 검색엔진 도구의 검색·AI 성과 보고 기능과 유입 자료도 함께 본다.

**첫 달 실행 순서**

| 시기 | 실행 | 이 순서인 이유 |
|---|---|---|
| 1주차 | 실제 문의·후기 수집, 표시·인증 확인, 한 봉의 양과 조리 과정 촬영. 핵심 구매 가이드 초안 완성 | 고객 불안 가설과 핵심 주장부터 확인해야 이후 글이 일관됨 |
| 2주차 | 구매 가이드를 준비하고 ‘물만 부어도 되는지’와 ‘40g의 양’ 소재를 채널별 원고·이미지로 제작 | 첫 구매의 사용법·분량 의문에 먼저 답함 |
| 3주차 | ‘출근 전 아침 준비’와 ‘사무실에서 먹는 과정’ 소재를 두 채널용으로 제작. 준비된 글 발행과 내부 이동·스토어 링크 점검 | 생활 상황에서 상품 확인으로 이어지는 흐름을 시험함 |
| 4주차 | ‘원재료 표시’와 ‘개별포장 보관’ 소재를 두 채널용으로 제작. 자료가 완성되면 시간별 식감 기록 추가 | 원료 신뢰와 사용 후 경험을 보강함 |

첫 달 후보 묶음은 구매 가이드 1개 + 탐색 소재 6개 + 직접 시험 기록 1개다. 각 소재의 두 채널 원고·이미지·검수까지 포함해 실제 발행 일정을 정한다. 위 일정은 제작 순서의 예시이며 확정 발행량이나 검색 공식이 아니다. 자료가 부족한 글은 결과를 만들어 채우지 말고 확보된 주제부터 발행한다. 첫 달을 검색 성과의 최종 판정 시점으로 삼지 않는다.

이후 매월 검색어·문의·스토어 이동을 검토한다. 구매 가이드로 연결되는 글의 주제를 확장하고, 방문은 많지만 다음 행동이 없는 글은 질문과 제품의 관련성을 다시 본다. 분기마다 원료 자료·구성·링크를 점검하고, 실제 변경이 있을 때 갱신한다.

**발행 전에 우선 바로잡을 상품 설명**

40명 시식이 최종 70:30 배합을 직접 검증했는지, 3분과 4분의 부드러움 표현을 어떤 조건으로 설명할지 먼저 확인한다. 품종의 2-AP·아밀로스 수치를 완제품의 성능으로 확대하지 않는다. 실제 검증 없이 성장·혈당·소화·질환 관련 효과를 블로그의 주력 유입 주제로 삼지 않는다. 이 상품에서 먼저 설명할 가치는 조리 편의, 실제 양과 식감, 원료의 투명성이다.
